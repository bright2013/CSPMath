## 整除、因数与倍数 【3】

若存在整数 k 使 b = a·k，则称 a **整除** b（记作 a | b），a 是 b 的**因数**，
b 是 a 的**倍数**。

* **质数（素数）**：大于 1 且只有 1 和自身两个正因数的整数：2, 3, 5, 7, 11, …
* **合数**：大于 1 且不是质数的整数。
* **指数**：aⁿ 表示 n 个 a 相乘；常用法则 aᵐ·aⁿ = aᵐ⁺ⁿ、(aᵐ)ⁿ = aᵐⁿ。

## 取整 【3】

* **下取整** ⌊x⌋：不超过 x 的最大整数，如 ⌊3.7⌋ = 3，⌊−2.3⌋ = −3。
* **上取整** ⌈x⌉：不小于 x 的最小整数，如 ⌈3.2⌉ = 4。
* C++ 中非负整数的除法向零取整，与非负数的下取整一致；操作数为负时需特别小心。

## 模运算与取余 【3】

a mod m 表示 a 除以 m（m > 0）的**余数**，取值范围 0 … m−1。

基本恒等式：

* (a + b) mod m = ((a mod m) + (b mod m)) mod m
* (a − b) mod m = ((a mod m) − (b mod m) + m) mod m
* (a · b) mod m = ((a mod m) · (b mod m)) mod m

这些性质可以控制中间结果的大小，是竞赛编程的基本功。

## 整数唯一分解定理 【3】

任意大于 1 的整数 n 都可以**唯一地**（不计顺序）分解为质数幂的乘积：

> n = p₁^a₁ · p₂^a₂ · … · pₖ^aₖ（p₁ < p₂ < … < pₖ 为质数）

例：360 = 2³ · 3² · 5。由分解式可得正因数个数为 (a₁+1)(a₂+1)…(aₖ+1)。

## 辗转相除法（欧几里得算法）【3】

通过反复取余求最大公约数（GCD）：

> gcd(a, b) = gcd(b, a mod b)，直到余数为 0。

例：gcd(252, 105) = gcd(105, 42) = gcd(42, 21) = gcd(21, 0) = 21。

由此还可求最小公倍数：lcm(a, b) = a·b / gcd(a, b)。

## 素数筛法 【4】

**埃氏筛法**：求不超过 n 的所有素数，从 p² 开始划去每个素数的倍数。
时间复杂度 O(n log log n)。

**线性筛法**：每个合数仅被其最小质因子筛去一次。时间复杂度 O(n)，还可以同时
递推欧拉函数 φ 等积性函数。
