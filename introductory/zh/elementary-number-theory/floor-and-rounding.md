# 取整 【3】

## 讲解

* **下取整** ⌊x⌋：不超过 x 的最大整数。
  ⌊3.7⌋ = 3，⌊5⌋ = 5，⌊−2.3⌋ = −3（注意是 −3 而不是 −2！）。
* **上取整** ⌈x⌉：不小于 x 的最小整数。
  ⌈3.2⌉ = 4，⌈5⌉ = 5，⌈−2.3⌉ = −2。
* **四舍五入**：最接近的整数，逢五向远离零方向进：round(3.5) = 4，round(3.4) = 3。

重要恒等式：对任意实数 x，有 ⌊x⌋ ≤ x < ⌊x⌋ + 1，以及 x − 1 < ⌈x⌉ ≤ x。

**C++ 中的取整**：整数 `/` 运算符**向零取整**：

* 7 / 2 = 3（= ⌊3.5⌋）——操作数非负时与下取整一致；
* −7 / 2 = −3，但 ⌊−3.5⌋ = −4——操作数为负时不同！

因此整数除法只在操作数非负时等价于下取整，出现负数时务必小心。

常用公式（a、b 为正整数）：

* a 个物品每 b 个分一组，完整组数：a / b = ⌊a/b⌋；
* 容量为 b 时装下 a 个物品所需的组数：⌈a/b⌉ = (a + b − 1) / b。

## 例题

**例 1.** ⌊7/2⌋ = 3，⌈7/2⌉ = 4。7 颗糖每盒装 2 颗，可装满 3 盒，要装完需 4 盒。

**例 2.** C++ 中的取整函数：

```cpp
#include <cmath>
floor(3.7);    // 3
floor(-2.3);   // -4
ceil(3.2);     // 4
round(3.5);    // 4
-7 / 2;        // -3（向零取整，不是下取整）
```

**例 3.** 正整数的上取整除法：

```cpp
long long pages = (n + perPage - 1) / perPage;   // ⌈n / perPage⌉
```

**例 4.** [10, 50] 中有多少个 4 的倍数？⌊50/4⌋ − ⌊9/4⌋ = 12 − 2 = 10。

## 练习

1. 计算：⌊11/3⌋、⌈11/3⌉、⌊−11/3⌋、⌈−11/3⌉。
   *（答案：3、4、−4、−3。）*
2. C++ 中 9 / 4、−9 / 4、9 / −4 的值各是多少？*（答案：2、−2、−2。）*
3. 一辆大巴坐 45 人，200 名学生需要多少辆车？写出一行 C++ 表达式。
   *（答案：(200 + 45 − 1) / 45 = 5。）*
4. [1, 1000] 中有多少个 8 的倍数？*（答案：⌊1000/8⌋ = 125。）*
5. 验证公式：对正整数 a、b，⌈a/b⌉ = ⌊(a + b − 1)/b⌋。用 a = 10, b = 4 和
   a = 12, b = 4 验证。
6. 编写程序：读入实数 x，在一行内输出 ⌊x⌋、⌈x⌉ 和四舍五入值。用 x = −2.5 测试。
