# 初等数论 (Elementary Number Theory)

初等数论研究整数的性质，是入门级（CSP-J）最常考的数学内容之一——大量竞赛题目
最终都归结为整除、余数、最大公约数或素数问题。

## 大纲条目

* 【3】整除、因数、倍数、指数、质（素）数、合数
* 【3】取整
* 【3】模运算与取余
* 【3】整数唯一分解定理
* 【3】辗转相除法（欧几里得算法）
* 【4】素数筛法：埃氏筛法与线性筛法
