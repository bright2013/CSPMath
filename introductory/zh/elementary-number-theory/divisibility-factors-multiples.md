# 整除、因数与倍数 【3】

整除、因数、倍数、指数、质（素）数、合数

## 讲解

若存在整数 k 使 b = a·k，则称 a **整除** b（记作 **a | b**）。此时：

* a 是 b 的**因数（约数）**；
* b 是 a 的**倍数**；
* b ÷ a 的余数为 0。

整除的常用性质：

* 若 a | b 且 a | c，则 a | (b ± c)，a | b·c；
* 若 a | b 且 b | c，则 a | c（传递性）；
* 若 a | b 且 b | a，则 |a| = |b|。

**指数**：aⁿ 表示 n 个 a 相乘。常用法则：

* aᵐ · aⁿ = aᵐ⁺ⁿ
* (aᵐ)ⁿ = aᵐⁿ
* a⁰ = 1（a ≠ 0）

**质数与合数：**

* **质数（素数）**：大于 1，且正因数只有 1 和它本身的整数：2, 3, 5, 7, 11, 13, …
* **合数**：大于 1 且不是质数的整数，即存在 1 和自身以外的因数。
* 1 既不是质数也不是合数；2 是唯一的偶质数。

**试除法判素数**：判断 n 是否为质数，只需试除到 √n——若 n = a·b 且 a ≤ b，
则必有 a ≤ √n。

## 例题

**例 1.** 7 整除 252 吗？整除：252 = 7 × 36，所以 7 | 252，7 是 252 的因数，
252 是 7 的倍数。

**例 2.** 36 的正因数：1, 2, 3, 4, 6, 9, 12, 18, 36，共 9 个。

**例 3.** 97 是质数吗？√97 < 10，试除 2, 3, 5, 7 均不整除，故 97 是质数。

**例 4（C++）.** 统计 [1, n] 中 k 的倍数个数：

```cpp
long long n = 1000, k = 7;
cout << n / k;        // 142，因为 ⌊1000/7⌋ = 142
```

**例 5（C++）.** O(√n) 试除法判素数：

```cpp
bool isPrime(long long n) {
    if (n < 2) return false;
    for (long long i = 2; i * i <= n; i++)
        if (n % i == 0) return false;
    return true;
}
```

## 练习

1. [1, 500] 中有多少个整数能被 6 整除？*（答案：⌊500/6⌋ = 83。）*
2. 求 60 的所有正因数，共有多少个？
   *（答案：1, 2, 3, 4, 5, 6, 10, 12, 15, 20, 30, 60，共 12 个。）*
3. 51, 59, 87, 91, 101 中哪些是质数？
   *（答案：59 和 101；51 = 3×17，87 = 3×29，91 = 7×13。）*
4. 不用计算器求 2¹⁰ 和 3⁵。*（答案：1024 和 243。）*
5. 编写程序：读入 n，在 O(√n) 时间内输出它的所有正因数。
   *（提示：对每个满足 i | n 的 i ≤ √n，i 和 n/i 都是因数。）*
6. [1, 1000] 中有多少个整数能被 3 或 5 整除？
   *（提示：容斥原理，⌊1000/3⌋ + ⌊1000/5⌋ − ⌊1000/15⌋ = 467。）*
