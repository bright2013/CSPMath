# 整数唯一分解定理 【3】

## 讲解

**算术基本定理**：任意大于 1 的整数 n 都可以分解为质数幂的乘积，且该分解
（不计因子的顺序）是**唯一的**：

> n = p₁^a₁ · p₂^a₂ · … · pₖ^aₖ，其中 p₁ < p₂ < … < pₖ 为质数，每个 aᵢ ≥ 1。

例：360 = 2³ · 3² · 5¹。

**有什么用。** 由分解式 n = p₁^a₁ · … · pₖ^aₖ 可得：

* **正因数个数**：d(n) = (a₁+1)(a₂+1)…(aₖ+1)；
* **正因数之和**：σ(n) = (1+p₁+…+p₁^a₁) · … · (1+pₖ+…+pₖ^aₖ)；
* n 是**完全平方数** ⇔ 每个 aᵢ 都是偶数；
* **用分解式求 GCD/LCM**：对每个质因子分别取最小（最大）指数。

**试除法分解质因数**：从 2 到 √n 依次试除，发现质因子就不断除尽；最后若剩下
大于 1 的数，它本身就是一个质因子。复杂度 O(√n)，可处理 n 到约 10¹²。

## 例题

**例 1.** 分解 360：360 = 2×180 = 2²×90 = 2³×45 = 2³×3²×5。

**例 2.** 360 = 2³·3²·5¹ 的因数个数：d(360) = (3+1)(2+1)(1+1) = 4 × 3 × 2 = 24。

**例 3.** 720 是完全平方数吗？720 = 2⁴·3²·5¹——5 的指数为奇数，所以不是。

**例 4（C++）.** 试除法分解质因数：

```cpp
void factorize(long long n) {
    for (long long p = 2; p * p <= n; p++) {
        while (n % p == 0) {
            cout << p << " ";   // 质因子 p
            n /= p;
        }
    }
    if (n > 1) cout << n;       // 剩下的质因子
}
// factorize(360) 输出：2 2 2 3 3 5
```

**例 5.** 用分解式求 gcd(360, 252)：
360 = 2³·3²·5，252 = 2²·3²·7 → gcd = 2²·3² = 36，lcm = 2³·3²·5·7 = 2520。

## 练习

1. 分解质因数：84、225、1001、2025。
   *（答案：2²·3·7；3²·5²；7·11·13；3⁴·5²。）*
2. 1000 = 2³·5³ 有多少个正因数？*（答案：4×4 = 16。）*
3. 144、200、576 中哪些是完全平方数？*（答案：144 = 12²，576 = 24²。）*
4. 求最小的恰有 6 个正因数的正整数 n。
   *（提示：6 = 6 或 6 = 2×3 → 形如 p⁵ 或 p¹q²。答案：12 = 2²·3。）*
5. 用质因数分解求 gcd(840, 462) 与 lcm(840, 462)。
   *（答案：840 = 2³·3·5·7，462 = 2·3·7·11 → gcd = 42，lcm = 9240。）*
6. 编写程序：读入 n（n ≤ 10¹²），按 `p1^a1 * p2^a2 * ...` 的格式输出分解式。
7. （挑战）用 σ 公式求 360 的所有正因数之和。
   *（答案：(1+2+4+8)(1+3+9)(1+5) = 15 × 13 × 6 = 1170。）*
