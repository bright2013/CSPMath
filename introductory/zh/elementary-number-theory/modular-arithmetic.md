# 模运算与取余 【3】

## 讲解

对正整数 m，**a mod m** 表示 a 除以 m 的余数，取值总是在 0, 1, …, m−1 中。
若 a 与 b 除以 m 的余数相同（即 m | (a − b)），则称 a 与 b **模 m 同余**，记作：

> a ≡ b (mod m)

**基本恒等式**（模运算的核心）：

* (a + b) mod m = ((a mod m) + (b mod m)) mod m
* (a − b) mod m = ((a mod m) − (b mod m) + m) mod m
* (a · b) mod m = ((a mod m) · (b mod m)) mod m

为什么重要：竞赛中经常要求"答案对 10⁹+7 取模"。在**每一步**都取模，可以让
中间结果始终保持很小，避免溢出。注意：入门级范围内**除法没有**类似的恒等式
——模意义下的除法需要模逆元（提高级内容）。

**C++ 注意**：`%` 是*取余*运算，结果符号与被除数一致：−7 % 3 = −1。
要得到 [0, m) 内的真正剩余，写成 `((a % m) + m) % m`。

**周期思想**：模 m 把问题归结为长度为 m 的循环——星期（mod 7）、钟点
（mod 12/24）、末位数字（mod 10）、奇偶性（mod 2）。

## 例题

**例 1.** 38 mod 5 = 3，因为 38 = 5 × 7 + 3。且 13 ≡ 38 (mod 5)，两者余数都是 3。

**例 2.** 不扩大数计算 (97 × 86) mod 7：
97 mod 7 = 6，86 mod 7 = 2，故 (97 × 86) mod 7 = (6 × 2) mod 7 = 12 mod 7 = 5。

**例 3.** 7²⁰²⁴ 的末位数字：7 的幂 mod 10 按 7, 9, 3, 1, 7, … 循环，周期为 4。
2024 mod 4 = 0，故末位是 1。

**例 4（C++）.** n 个数求和对 1000000007 取模，不溢出：

```cpp
const long long MOD = 1000000007;
long long sum = 0, x;
for (int i = 0; i < n; i++) {
    cin >> x;
    sum = (sum + x % MOD) % MOD;   // 每一步都取模
}
```

**例 5（C++）.** 可能为负的值的安全取余：

```cpp
long long r = ((a % m) + m) % m;   // 保证在 [0, m) 内
```

## 练习

1. 计算：100 mod 7；2¹⁰ mod 5；(25 × 13 + 7) mod 11。
   *（答案：2；1024 mod 5 = 4；332 mod 11 = 2。）*
2. 3²⁰²⁵ 的末位数字是多少？*（提示：3 的幂 mod 10 按 3, 9, 7, 1 循环。答案：3。）*
3. 今天是星期一，100 天后是星期几？*（答案：100 mod 7 = 2 → 星期三。）*
4. C++ 中求 −13 % 5 的值，再求 −13 模 5 的真正剩余。*（答案：−3；真正剩余为 2。）*
5. 手算 (123456789 × 987654321) mod 100。*（答案：(89 × 21) mod 100 = 1869
   mod 100 = 69。）*
6. 编写程序：读入 n（n ≤ 20），输出 n! 的末两位数字。
   *（提示：每步只保留 (结果 × i) mod 100；注意从 n = 10 起答案恒为 00。）*
