# 辗转相除法（欧几里得算法）【3】

## 讲解

**最大公约数** gcd(a, b) 是同时整除 a 和 b 的最大正整数。**辗转相除法**通过
反复取余来求它：

> gcd(a, b) = gcd(b, a mod b)，直到余数为 0；最后一个非零余数即为最大公约数。

**为什么正确**：若 a = b·q + r，则 a 和 b 的每个公约数也整除 r = a − b·q，
而 b 和 r 的每个公约数也整除 a——所以 (a, b) 与 (b, r) 的公约数完全相同。

**速度**：每两步数至少缩小一半，因此步数为 O(log min(a, b))，即使对 64 位
整数也是瞬间完成。

**最小公倍数**：

> lcm(a, b) = a · b / gcd(a, b)

先除后乘（a / gcd(a, b) · b）可避免溢出。C++17 起还可使用 `<numeric>` 中的
`std::gcd`、`std::lcm`（GNU 扩展有 `std::__gcd`）。

若 gcd(a, b) = 1，则称 a 与 b **互质（互素）**。

## 例题

**例 1.** 求 gcd(252, 105)：

```
252 = 105 × 2 + 42
105 =  42 × 2 + 21
 42 =  21 × 2 +  0   →  gcd = 21
```

**例 2.** 约分 252/105：同除以 gcd = 21，得 12/5。

**例 3（C++）.** 递归版 GCD 与 LCM：

```cpp
long long gcd(long long a, long long b) {
    return b == 0 ? a : gcd(b, a % b);
}

long long lcm(long long a, long long b) {
    return a / gcd(a, b) * b;   // 先除后乘，避免溢出
}
```

**例 4.** lcm(12, 18) = 12 × 18 / gcd(12, 18) = 216 / 6 = 36。

**例 5.** 35 与 12 互质吗？gcd(35, 12) = gcd(12, 11) = gcd(11, 1) =
gcd(1, 0) = 1 → 互质。

## 练习

1. 用辗转相除法手算：gcd(1071, 462)；gcd(240, 105)。*（答案：21；15。）*
2. 将分数 1071/462 约到最简。*（答案：同除以 21 → 51/22。）*
3. 求 lcm(15, 20, 24)。*（提示：lcm 满足结合律。答案：120。）*
4. 两个齿轮分别有 48 齿和 36 齿，第一个齿轮转多少圈后接触点重新对齐？
   *（答案：lcm(48, 36) / 48 = 144 / 48 = 3 圈。）*
5. 编写程序：读入 n 对 (a, b)，输出每对的 gcd 与 lcm。
6. [1, 100] 中有多少个整数与 36 互质？
   *（提示：36 = 2²·3²，用容斥去掉 2 或 3 的倍数。答案：100 − 50 − 33 + 16 = 33。）*
7. （挑战）证明相邻斐波那契数互质：gcd(Fₙ, Fₙ₊₁) = 1。
   *（提示：gcd(Fₙ₊₁, Fₙ) = gcd(Fₙ, Fₙ₊₁ − Fₙ) = gcd(Fₙ, Fₙ₋₁)。）*
