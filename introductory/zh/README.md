# 入门级数学 (Introductory Level Mathematics)

本空间覆盖《全国青少年信息学奥林匹克系列竞赛大纲（2025 年修订版）》**入门级
（2.1，对应 CSP-J）中 2.1.5 "数学与其他"** 的全部数学要求。

## 大纲范围

| 主题 | English |
| --- | --- |
| 数及其运算 | Numbers and their operations |
| 初等数学 | Elementary mathematics |
| 初等数论 | Elementary number theory |
| 离散与组合数学 | Discrete and combinatorial mathematics |
| 其他 | Others |

## 难度系数

大纲中每个条目都标注了难度系数 【1】–【5】，由 CCF NOI 科学委员会给出。
本书在每个条目旁保留相同标注。

## 来源

《全国青少年信息学奥林匹克系列竞赛大纲（2025 年修订版）》，CCF NOI 科学委员会审定。
