# 集合 【2】

## 讲解

**集合**是**互不相同**的对象（称为元素）的整体。元素没有顺序，重复不计：
{1, 2, 2, 3} = {1, 2, 3} = {3, 2, 1}。

核心概念：

* **属于**：a ∈ A（"a 属于 A"），a ∉ A（"a 不属于 A"）。
* **子集**：若 A 的每个元素都在 B 中，则 A ⊆ B。**空集** ∅ 是任何集合的子集。
  n 元集合恰有 2ⁿ 个子集。
* **运算**：
  * 并集 A ∪ B——属于 A 或 B 的元素；
  * 交集 A ∩ B——同时属于 A 和 B 的元素；
  * 差集 A ∖ B——属于 A 但不属于 B 的元素；
  * 补集 Ā——全集 U 中不属于 A 的元素。
* **基数** |A|：有限集合中元素的个数。

**两个集合的容斥原理**：

> |A ∪ B| = |A| + |B| − |A ∩ B|

**在程序设计中**，集合对应"这个值是否出现过"——常用布尔数组、`std::set` 或
`std::unordered_set` 实现。

## 例题

**例 1.** A = {1, 2, 3, 4}，B = {3, 4, 5}。则
A ∪ B = {1, 2, 3, 4, 5}，A ∩ B = {3, 4}，A ∖ B = {1, 2}，|A| = 4。

**例 2.** 集合 {a, b, c} 有 2³ = 8 个子集：
∅, {a}, {b}, {c}, {a,b}, {a,c}, {b,c}, {a,b,c}。

**例 3.** 某班 40 人，25 人打篮球，18 人踢足球，10 人两项都参加。至少参加一项
的有多少人？|A ∪ B| = 25 + 18 − 10 = 33，故 40 − 33 = 7 人两项都不参加。

**例 4（C++）.** 统计数组中不同值的个数：

```cpp
#include <unordered_set>
unordered_set<int> s(a, a + n);
cout << s.size();   // 不同元素的个数
```

**例 5（C++）.** 用布尔数组做属于判断（值域 [0, 10⁶]）：

```cpp
vector<bool> seen(1000001, false);
seen[x] = true;            // 插入
if (seen[y]) { ... }       // y ∈ 集合？
```

## 练习

1. 设 A = {2, 4, 6, 8}，B = {4, 8, 12}。求 A ∪ B、A ∩ B、A ∖ B 与 |A ∪ B|。
   *（答案：{2,4,6,8,12}；{4,8}；{2,6}；5。）*
2. {1, 2, 3, 4, 5} 有多少个子集？其中非空子集有多少个？
   *（答案：2⁵ = 32；31。）*
3. 50 名学生中，30 人喜欢数学，26 人喜欢物理，12 人两者都喜欢。两者都不喜欢的
   有多少人？*（答案：50 − (30 + 26 − 12) = 6。）*
4. 判断真假：∅ ∈ {∅}？∅ ⊆ {1, 2}？*（答案：真；真。）*
5. [1, 100] 中有多少个整数能被 4 或 6 整除？
   *（提示：4 的倍数 ∪ 6 的倍数，注意 lcm(4,6) = 12。答案：25 + 16 − 8 = 33。）*
6. 编写程序：读入 n 个整数，输出不同值的个数，以及恰好出现一次的值的个数。
7. （挑战）A = {x : x | 12}，B = {x : x | 18}（正因数集合）。列出 A ∩ B，并思考
   它与 gcd(12, 18) 的关系。*（答案：{1, 2, 3, 6}；最大元即最大公约数。）*
