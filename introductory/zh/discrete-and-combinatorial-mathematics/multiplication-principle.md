# 乘法原理 【2】

## 讲解

**乘法原理（分步计数原理）**：完成一件事需要分**步骤**进行，第 1 步有 n₁ 种
方法，第 2 步有 n₂ 种方法，……，第 k 步有 nₖ 种方法，则总方法数为：

> n₁ · n₂ · … · nₖ

适用条件是：各步取法的每一种组合都给出一个不同的合法结果。后一步的可选数目
可以依赖于前面的选择，但在那一步必须是可数的。

典型措辞："先……再……""各选一个"。形象的图景是树形图：叶子数等于各层分支数
之积。

加法与乘法的区别：**加法**把一件事分成互斥的几类（要么这样、要么那样）；
**乘法**把必须依次完成的几个子任务串起来（先这样、再那样）。很多题目两者都
要用——用加法分类，每类内部用乘法计数。

## 例题

**例 1.** 3 件上衣、4 条裤子 → 3 × 4 = 12 种搭配。

**例 2.** 三位数共有多少个？百位 9 种（1–9），十位、个位各 10 种 →
9 × 10 × 10 = 900。

**例 3.** 各位数字**互不相同**的三位数有多少个？
百位 9 种；十位 9 种（可以用 0，但不能与百位重复）；个位 8 种 →
9 × 9 × 8 = 648。

**例 4.** 长度为 8 的二进制串共有 2⁸ = 256 个；"2 个字母 + 3 个数字"的车牌共
26² × 10³ = 676 000 种。

**例 5（两原理并用）.** 各位数字互不相同的**偶**三位数有多少个？按个位分类
（加法）：
- 个位为 0：百位 9 种，十位 8 种 → 72；
- 个位 ∈ {2,4,6,8}：个位 4 种，百位 8 种（不为 0 且不与个位重复），十位 8 种
  → 4 × 8 × 8 = 256。
合计 72 + 256 = 328。

**例 6（C++）.** 枚举验证：

```cpp
int cnt = 0;
for (int h = 1; h <= 9; h++)
    for (int t = 0; t <= 9; t++)
        for (int u = 0; u <= 9; u++)
            if (u % 2 == 0 && h != t && t != u && h != u) cnt++;
// cnt == 328
```

## 练习

1. 冰淇淋店有 5 种口味、3 种规格、2 种蛋筒，共有多少种点单方式？
   *（答案：30。）*
2. 四位数有多少个？其中奇数有多少个？
   *（答案：9·10³ = 9000；9·10·10·5 = 4500。）*
3. 5 本不同的书在书架上排成一排，有多少种排法？*（答案：5! = 120。）*
4. 用字母 A–Z 组成长度为 5 且字母不重复的串，有多少个？
   *（答案：26·25·24·23·22 = 7 893 600。）*
5. 密码为 4 位数字。共有多少种密码？各位数字不同的有多少？以 0 开头且各位
   不同的有多少？*（答案：10⁴ = 10 000；10·9·8·7 = 5040；1·9·8·7 = 504。）*
6. 编写程序：读入 n 和 k，输出在 n 个字母的字母表上组成长度为 k、字母不重复的
   串的个数（假设 k ≤ n ≤ 26）。
7. （挑战）各位数字互不相同且能被 5 整除的三位数有多少个？
   *（提示：按个位为 0 或 5 分类。答案：9·8 + 8·8 = 136。）*
