# 加法原理 【2】

## 讲解

**加法原理（分类计数原理）**：完成一件事有若干**互斥**的方式，第 i 类方式有
nᵢ 种方法，则总方法数为：

> n₁ + n₂ + … + nₖ

关键条件是各类**互不重叠**——每种结果恰好属于一类。若分类有重叠，直接相加
会重复计数，需要用容斥原理修正：|A ∪ B| = |A| + |B| − |A ∩ B|。

典型措辞："要么……要么……""乘火车**或**汽车"。如何选择分类标准往往是解题的
全部关键；好的分类应做到**不重不漏**。

## 例题

**例 1.** 从 A 地到 B 地，可乘 3 趟火车之一或 4 班汽车之一：3 + 4 = 7 种走法。

**例 2.** 数字之和为 9 的两位数有多少个？按十位数字分类：
18, 27, 36, 45, 54, 63, 72, 81, 90，共 9 个。（十位定为 d 时恰有一个。）

**例 3.** [1, 100] 中能被 3 **或** 5 整除的整数有多少个？"被 3 整除"（33 个）
与"被 5 整除"（20 个）两类**有重叠**：15 的倍数（6 个）被重复计算。正确答案：
33 + 20 − 6 = 47。直接相加就错了。

**例 4（C++）.** 统计 [1, n] 中末位是 0 或 5 的整数个数：

```cpp
long long ans = 0;
for (int i = 1; i <= n; i++)
    if (i % 10 == 0 || i % 10 == 5) ans++;   // 两个互斥的类
```

**例 5.** 菜单有 4 种前菜、6 种主菜、3 种甜点。只点一道菜，共有
4 + 6 + 3 = 13 种选择。

## 练习

1. 书架上有 5 本数学书和 7 本小说，任取一本有多少种取法？*（答案：12。）*
2. [1, 200] 中有多少个整数能被 2 或 3 整除？
   *（答案：100 + 66 − 33 = 133。）*
3. 各位数字都是偶数的三位数有多少个？都是奇数的呢？各位数字同奇偶的呢？
   *（答案：4·5·5 = 100；5³ = 125；100 + 125 = 225。）*
4. 从 4 个红球、3 个绿球、5 个蓝球中任取一个红球或蓝球，有多少种取法？
   *（答案：4 + 5 = 9。）*
5. 统计 [1, 1000] 中含有数字 7 的整数个数。*（提示：数补集——不含数字 7 的数，
   再用 1000 减去。答案：271。）*
6. 编写程序：读入 n，统计 [1, n] 中能被 3 和 5 之一、但不能同时被两者整除的
   整数个数。*（提示：两类相加后减去两倍重叠。检验 n = 100 → 33 + 20 − 2×6 = 41。）*
7. （挑战）[1, 100] 中有多少个整数能被 2、3 或 5 整除？
   *（提示：三集合容斥。答案：50 + 33 + 20 − 16 − 10 − 6 + 3 = 74。）*
