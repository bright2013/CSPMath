# 杨辉三角 【4】

## 讲解

**杨辉三角**（南宋杨辉 1261 年记载，西方称帕斯卡三角）把二项式系数排成三角
形。第 n 行（从第 0 行起）依次是：

> C(n, 0), C(n, 1), …, C(n, n)

```
1
1   1
1   2   1
1   3   3   1
1   4   6   4   1
1   5  10  10   5   1
```

**构造规则**：每个数等于它肩上两数之和：

> C(n, m) = C(n−1, m−1) + C(n−1, m)

这正是组合的递推式，所以杨辉三角就是二项式系数表。

**值得掌握的性质：**

* 对称性：每行正读反读相同（C(n, m) = C(n, n−m)）；
* 行和：第 n 行各数之和为 2ⁿ；
* 二项式定理：(a + b)ⁿ = Σₖ C(n, k) aⁿ⁻ᵏ bᵏ——例如
  (a+b)⁴ = a⁴ + 4a³b + 6a²b² + 4ab³ + b⁴；
* 各条斜线上依次是自然数、三角数、四面体数……

**在程序设计中**，杨辉三角用简单的动态规划递推得到——与 C(n, m) 的递推完全
相同，是 O(n²) 求出 n 以内所有二项式系数的标准方法。

## 例题

**例 1.** 第 5 行：1, 5, 10, 10, 5, 1。验证 10 = 4 + 6（肩上两数）。

**例 2.** 用第 3 行展开 (a + b)³：a³ + 3a²b + 3ab² + b³。

**例 3.** 近似计算 (1.01)⁴：(1 + 0.01)⁴ = 1 + 4(0.01) + 6(0.01)² +
4(0.01)³ + (0.01)⁴ ≈ 1.04060401。

**例 4（C++）.** 打印前 n 行：

```cpp
long long C[35][35];
for (int i = 0; i < n; i++) {
    for (int j = 0; j <= i; j++) {
        C[i][j] = (j == 0 || j == i) ? 1 : C[i-1][j-1] + C[i-1][j];
        cout << C[i][j] << " ";
    }
    cout << "\n";
}
```

**例 5.** 第 10 行之和为 2¹⁰ = 1024——按大小统计 10 元集合的子集：
C(10,0) + C(10,1) + … + C(10,10)。

## 练习

1. 写出杨辉三角的第 6、7 行。
   *（答案：1 6 15 20 15 6 1；1 7 21 35 35 21 7 1。）*
2. 第 12 行各数之和是多少？*（答案：4096。）*
3. 展开 (a + b)⁵。*（答案：a⁵ + 5a⁴b + 10a³b² + 10a²b³ + 5ab⁴ + b⁵。）*
4. 求 (1 + x)⁸ 中 x³ 的系数。*（答案：C(8, 3) = 56。）*
5. 用二项式定理计算 (2 + 1)⁵ 与 (2 − 1)⁵；把两个展开式相加会发生什么？
   *（答案：3⁵ = 243 与 1；相加后奇次项消去。）*
6. 编写程序：打印杨辉三角前 n 行（n ≤ 30），并验证每行之和是 2 的幂。
7. （挑战）曲棍球棒恒等式：C(2,2) + C(3,2) + C(4,2) + … + C(8,2) = C(9, 3)。
   数值验证，并在三角形中找到它。*（答案：84。）*
