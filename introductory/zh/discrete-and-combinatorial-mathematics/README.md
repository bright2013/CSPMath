# 离散与组合数学 (Discrete and Combinatorial Mathematics)

组合数学的核心是**计数**：完成一件事、选取或安排若干对象，各有多少种方法？
在入门级（CSP-J）中，它既直接以计数题出现，也是分析算法的基础工具。
