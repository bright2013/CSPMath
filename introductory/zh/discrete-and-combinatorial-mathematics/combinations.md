# 组合 【4】

## 讲解

**组合**是**无序**的选取。从 n 个不同元素中选出 m 个（不考虑选取顺序）的
方法数称为二项式系数：

> C(n, m) = n! / (m! · (n−m)!) = A(n, m) / m!

把 A(n, m) 除以 m!，是因为同一组元素的 m! 种排列在组合里只算一次：
{1, 2, 3} 与 {3, 1, 2} 是同一个组合，却是不同的排列。

**重要性质：**

* 对称性：C(n, m) = C(n, n−m)——"选出的"与"留下的"一一对应；
* 递推式（杨辉恒等式）：C(n, m) = C(n−1, m−1) + C(n−1, m)；
* 行和：C(n, 0) + C(n, 1) + … + C(n, n) = 2ⁿ（n 元集合的全部子集）；
* 边界：C(n, 0) = C(n, n) = 1。

**安全地计算 C(n, m)**：边乘边除，或用递推（动态规划）。数值增长很快——
C(60, 30) ≈ 1.18 × 10¹⁷ 还能放进 `long long`，C(67, 33) 就溢出了。

## 例题

**例 1.** C(5, 2) = 10：从 5 名队员中选 2 人组成双打组合。
验证：A(5, 2) / 2! = 20 / 2 = 10。

**例 2.** C(10, 3) = 10! / (3!·7!) = (10·9·8)/(3·2·1) = 120。

**例 3.** 从 7 男 4 女中选 3 人组成委员会，要求恰好 2 名女生：
选女生 C(4, 2) = 6，选男生 C(7, 1) = 7 → 6 × 7 = 42（对两组分别计数再用
乘法原理）。

**例 4.** 8 元集合有多少个子集？2⁸ = 256——二项式系数的行和。

**例 5（C++）.** 乘除交替计算 C(n, m)：

```cpp
long long comb(int n, int m) {
    if (m > n - m) m = n - m;      // 对称性
    long long r = 1;
    for (int i = 1; i <= m; i++)
        r = r * (n - m + i) / i;   // 每一步都整除
    return r;
}
```

**例 6（C++）.** 用杨辉递推计算 C(n, m)（需要对质数取模时尤其常用）：

```cpp
for (int i = 0; i <= n; i++) {
    C[i][0] = C[i][i] = 1;
    for (int j = 1; j < i; j++)
        C[i][j] = C[i-1][j-1] + C[i-1][j];
}
```

## 练习

1. 计算：C(6, 3)、C(8, 2)、C(10, 4)。*（答案：20；28；210。）*
2. 从 12 名学生中选出 4 人小组，有多少种选法？*（答案：495。）*
3. 凸 n 边形有多少条对角线？
   *（提示：C(n, 2) 数出所有顶点间线段，再减去 n 条边。答案：n(n−3)/2。）*
4. 披萨店有 8 种配料，必须恰好选 3 种，有多少种组合？*（答案：56。）*
5. 从 5 男 6 女中选 5 人委员会，要求至少 3 名女性。
   *（提示：按恰好 3、4、5 名女性分类相加。
   答案：C(6,3)C(5,2) + C(6,4)C(5,1) + C(6,5) = 200 + 75 + 6 = 281。）*
6. 直接计算验证：C(10, 3) = C(10, 7)，以及 C(8, 0) + … + C(8, 8) = 2⁸。
7. 编写程序：读入 n、m，输出 C(n, m)。要求 n 到 60 不溢出，并说明 n 更大时会
   出什么问题。
8. （挑战）从 (0, 0) 走到 (7, 5)，每步只能向右（R）或向上（U），有多少条路径？
   *（提示：每条路径是 12 步中选出哪 5 步向上。答案：C(12, 5) = 792。）*
