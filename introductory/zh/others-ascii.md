## 什么是 ASCII

**ASCII（美国信息交换标准代码）**为每个字符分配一个 7 位编码（0–127），是
计算机中字符表示的基础。

需要记住的关键区间：

| 字符 | 十进制编码 |
| --- | --- |
| '0'–'9' | 48–57 |
| 'A'–'Z' | 65–90 |
| 'a'–'z' | 97–122 |
| 空格 | 32 |

常用结论：

* 数字字符连续：'5' − '0' = 5，可把数字字符转为数值。
* 大小写字母相差 32：'a' − 'A' = 32。
* 0–31 与 127 是控制字符（如换行为 10）。

在 C/C++ 中，`char` 存储的就是其 ASCII 码，因此字符可以直接参与算术运算和
比较。
