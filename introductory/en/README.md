# Introductory Level Mathematics (入门级数学)

This space covers the mathematics requirements of **Section 2.1.5 "Mathematics and
Others" (数学与其他)** of the NOI Syllabus (2025 Edition), Introductory Level (入门级,
corresponding to CSP-J).

## Syllabus scope

| Topic | Chinese |
| --- | --- |
| Numbers and their operations | 数及其运算 |
| Elementary mathematics | 初等数学 |
| Elementary number theory | 初等数论 |
| Discrete and combinatorial mathematics | 离散与组合数学 |
| Others | 其他 |

## Difficulty coefficients

Every syllabus item is tagged with a difficulty coefficient 【1】–【5】 assigned by the
CCF NOI Scientific Committee. The same tags are kept next to each item in this book.
