# Elementary Number Theory (初等数论) — Advanced Level

Advanced number theory turns the introductory toolkit (congruences, GCD, primes)
into a system of powerful theorems. These are the standard weapons for modular
computation in contests.

## Syllabus items

* 【5】Congruences (同余式)
* 【7】Euler's theorem and Euler's totient function (欧拉定理和欧拉函数)
* 【7】Fermat's little theorem (费马小定理)
* 【7】Wilson's theorem (威尔逊定理)
* 【7】Bézout's identity (裴蜀定理)
* 【7】Modular inverse (模运算意义下的逆元)
* 【7】Extended Euclidean algorithm (扩展欧几里得算法)
* 【7】Chinese remainder theorem (中国剩余定理)
