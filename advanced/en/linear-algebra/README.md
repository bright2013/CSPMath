# Linear Algebra (线性代数) — Advanced Level

Linear algebra enters competitive programming through systems of linear equations,
matrix exponentiation for linear recurrences, and geometric computations.

## Syllabus items

* 【5】Concepts of vectors and matrices (向量与矩阵的概念)
* 【6】Vector operations (向量的运算)
* 【6】Elementary matrix transformations (矩阵的初等变换)
* 【6】Matrix operations: addition, subtraction, multiplication, transpose
  (矩阵的运算：加法、减法、乘法与转置)
* 【6】Special matrices: identity, triangular, symmetric, sparse
  (特殊矩阵的概念：单位阵、三角阵、对称阵和稀疏矩阵)
* 【7】Gaussian elimination (高斯消元法)
