# Advanced Level Mathematics (提高级数学)

This space covers the mathematics requirements of **Section 2.2.5 "Mathematics and
Others" (数学与其他)** of the NOI Syllabus (2025 Edition), Advanced Level (提高级,
corresponding to CSP-S).

## Syllabus scope

| Topic | Chinese |
| --- | --- |
| Elementary mathematics (senior high school) | 初等数学 |
| Elementary number theory | 初等数论 |
| Discrete and combinatorial mathematics | 离散与组合数学 |
| Linear algebra | 线性代数 |

## Difficulty coefficients

Every syllabus item is tagged with a difficulty coefficient 【5】–【7】 assigned by the
CCF NOI Scientific Committee. The same tags are kept next to each item in this book.

## Prerequisites

This level builds directly on the **Introductory Level** math topics (see the
Introductory Math space): base arithmetic, junior-high algebra and geometry,
divisibility, modular arithmetic, the Euclidean algorithm, prime sieves, basic
counting, permutations and combinations.
