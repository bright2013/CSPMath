# 多重集合 【6】

## 讲解

**多重集合（multiset）**与普通集合的区别在于元素**可以重复出现**。记作
{a, a, b}，称 a 的**重数**为 2，b 的重数为 1；各元素重数之和称为多重集合的
**基数**。

* 作为多重集合，{1, 1, 2} ≠ {1, 2}；
* 多重集的并、交：重数分别取最大、最小；
* 各类元素重数为 n₁, …, nₖ 的多重集，基数为 n = n₁ + … + nₖ。

**为什么重要**：现实中大量计数问题含有"不可分辨的副本"——单词 BALL 中有两个
L；把相同的苹果分给孩子是多重集问题。接下来的[多重集排列](multiset-permutations.md)
与[多重集组合](multiset-combinations.md)都建立在此之上。

**在程序设计中**，多重集表现为计数数组 `cnt[v]` 或 `std::map<值, 次数>`；
C++ 也直接提供 `std::multiset`。

## 例题

**例 1.** MISSISSIPPI 的字母构成多重集 {M, I×4, S×4, P×2}，基数 11。

**例 2.** A = {1, 1, 2, 3}，B = {1, 2, 2}：A ∪ B = {1, 1, 2, 2, 3}（重数取
max），A ∩ B = {1, 2}（重数取 min）。

**例 3.** 掷两颗**不可分辨**的骰子：结果是 {a, b}（a ≤ b）的多重集，共
C(6+2−1, 2) = 21 种（不是 36，因为 {2,5} 与 {5,2} 相同）。

**例 4（C++）.** 计数数组即多重集：

```cpp
int cnt[26] = {};
for (char c : s) cnt[c - 'a']++;   // 字符串 s 的字母多重集
```

**例 5.** {a×2, b×1} 的不同子多重集个数：a 取 0–2 个，b 取 0–1 个 →
3 × 2 = 6（含空集）。

## 练习

1. 写出 360 的质因子多重集（含重数）。*（答案：{2×3, 3×2, 5×1}。）*
2. {x×3, y×2, z×1} 有多少个不同的子多重集？*（答案：4·3·2 = 24。）*
3. 设 A = {1×3, 2×1}，B = {1×1, 2×4, 3×2}，求 A ∪ B 与 A ∩ B。
   *（答案：{1×3, 2×4, 3×2}；{1×1, 2×1}。）*
4. 掷三颗不可分辨的骰子，有多少种不同结果？*（答案：C(6+3−1, 3) = 56。）*
5. 面包店有 4 种面包，买 6 个（种类可重复），有多少种不同的篮子？
   *（答案：C(6+4−1, 4−1) = C(9, 3) = 84——多重集组合，详见后两页。）*
6. 编写程序：读入字符串，输出重数最大的字母及其重数。
7. （挑战）证明 {a₁^n₁, …, aₖ^nₖ} 的子多重集个数为 ∏(nᵢ + 1)，并与唯一分解
   定理中的因数个数公式联系起来。
