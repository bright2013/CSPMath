# 多重集合 【6】

Multisets

## 讲解

**多重集合**和集合类似，但元素可以**出现多次**。记作 {a, a, b}，带重数：a×2, b×1。
元素的**重数**是它出现的次数；多重集合的**基数**是所有重数之和。

* 记号：作为多重集合 {1, 1, 2} ≠ {1, 2}。
* 多重集合的并/交：重数取 **max**（交取 **min**）——不是求和，这是常见错误。
  （重数求和得到的是*多重集并* A ⊎ B，是另一种运算。）
* 重数为 n₁, n₂, …, nₖ 的多重集合，基数为 n = n₁ + … + nₖ。

**多重集合为什么在计数中重要**：真实计数问题大多涉及不可区分的副本——单词 BALL 有
重复的 L；把相同的苹果分给孩子是多重集合问题。集合反倒是自然界中的例外。接下来两页
（多重集合的[排列](multiset-permutations.md)与[组合](multiset-combinations.md)）直接
建立在它之上，分别回答两个基本问题：*排成一排*（顺序重要）和*选出子集*（顺序不重要）。

**数子多重集**：从 {a₁^n₁, …, aₖ^nₖ} 中，每个元素 aᵢ 可以取 0, 1, …, nᵢ 个——
彼此独立——共 ∏(nᵢ + 1) 个子多重集。注意它与约数个数公式的平行关系：
p₁^a₁·…·pₖ^aₖ 的约数恰好是其质因子多重集合的子多重集。

**编程中**，多重集合以频率数组 `cnt[v]` 或 `std::map<值, 个数>` 出现；C++ 甚至内置
`std::multiset`（有序）和 `std::unordered_multiset`。滑窗频率统计、变位词判断、众数
查找都是多重集合计算。

## 例题

**例 1.** MISSISSIPPI 的字母构成多重集合 {M, I×4, S×4, P×2}，基数为 11。

**例 2.** A = {1, 1, 2, 3}，B = {1, 2, 2}：A ∪ B = {1, 1, 2, 2, 3}（重数取 max），
A ∩ B = {1, 2}（重数取 min）。

**例 3.** 掷两颗相同的骰子：结果是多重集合 {a, b}（a ≤ b）——共 C(6+2−1, 2) = 21
种不同结果（不是 36，因为 {2,5} 和 {5,2} 相同）。相同骰子的概率问题必须给结果加权：
{2,5} 的概率是 {3,3} 的两倍。

**例 4（C++）.** 频率数组即多重集合：

```cpp
int cnt[26] = {};
for (char c : s) cnt[c - 'a']++;   // s 的字母多重集合
```

**例 5.** {a×2, b×1} 的子多重集个数：a 取 0–2 个，b 取 0–1 个 → 3 × 2 = 6（含空集）。

**例 6.** 变位词判断："listen" 与 "silent" 是变位词，当且仅当字母多重集合相等——
O(26) 比较两个 26 项频率数组。

## 练习

1. 写出 360 的质因子多重集合（带重数）。*（答案：{2×3, 3×2, 5×1}。）*
2. {x×3, y×2, z×1} 有多少个子多重集？*（答案：4·3·2 = 24。）*
3. 已知 A = {1×3, 2×1}，B = {1×1, 2×4, 3×2}，求 A ∪ B 和 A ∩ B。
   *（答案：{1×3, 2×4, 3×2}；{1×1, 2×1}。）*
4. 掷三颗相同的骰子，有多少种不同结果？*（答案：C(6+3−1, 3) = 56。）*
5. 面包店卖 4 种包子，买 6 个（种类可重复），多少种不同的篮子？
   *（答案：C(6+4−1, 4−1) = C(9, 3) = 84——多重集合组合，详见后面两页。）*
6. 若一个串把另一个串改至多一个字母就能得到，称它们"半变位词"。给定频率数组，如何
   判断？*（提示：两个数组的绝对差之和必须为 2。）*
7. 写程序：读入一个字符串，输出重数最高的字母及其重数。
8.（挑战）证明 {a₁^n₁, …, aₖ^nₖ} 的子多重集个数为 ∏(nᵢ + 1)——并把它与唯一分解
   定理的约数个数公式联系起来。
