# 特殊矩阵的概念：单位阵、三角阵、对称阵和稀疏矩阵 【6】

Special Matrices

## 讲解

* **单位阵** I：方阵，aᵢᵢ = 1，其余元素为 0。它是乘法单位元：A·I = I·A = A——
  相当于数字 1。作为线性映射它什么也不做：每个向量原地不动。
* **三角阵**：**上三角**满足 aᵢⱼ = 0（i > j，对角线以下全零）；**下三角**则对角线
  以上全零。三角阵的乘积与逆仍是三角阵；行列式等于对角线元素之积。
* **对称阵**：Aᵀ = A，即 aᵢⱼ = aⱼᵢ——沿主对角线翻转后不变。只需存 n(n+1)/2 个元素。
  *无向图*的邻接矩阵都是对称阵。
* **稀疏矩阵**：绝大多数元素为零。只存非零元：三元组 (行, 列, 值)——**坐标表
  （COO）**——或用图的语言说，邻接表。

**为什么三角阵是目标而非起点**：[高斯消元](gaussian-elimination.md)的终点就是上三角
阵，这正是消元的意义所在——三角方程组用回代 O(n²) 即可解出。三角形让方程解耦到
可以直接读出答案的程度。

**为什么稀疏性统治竞赛**：n 个顶点 m 条边的图，邻接矩阵要 O(n²) 空间，邻接表只要
O(n + m)。真实竞赛图都是稀疏的（m ≪ n²），邻接表完胜；反过来，稠密代数任务（用
A^L 数路径）直接用矩阵。选择哪种表示*本身*就是算法决策。

## 例题

**例 1.** I₃ = [[1,0,0],[0,1,0],[0,0,1]]；验证 [[1,2],[3,4]]·I₂ = [[1,2],[3,4]]。

**例 2.** 上三角：[[2, 5, 1], [0, 3, 4], [0, 0, 7]]——行列式为 2·3·7 = 42（对角线
之积）。

**例 3.** 对称：[[1, 7, 3], [7, 2, 5], [3, 5, 0]]。无向图的邻接矩阵总是对称的：
边 i–j 同时出现在 (i, j) 和 (j, i)。

**例 4（C++）.** 三元组与邻接表两种稀疏存储：

```cpp
struct Entry { int r, c; double v; };      // COO 三元组
vector<Entry> sparse = {{0, 1, 2.5}, {3, 3, -1.0}};

vector<vector<pair<int,int>>> g(n);        // 邻接表：(邻居, 权值)
g[u].push_back({v, w});
```

**例 5.** 高斯消元中矩阵最终变成上三角——这正是消元的意义：三角方程组回代只需
O(n²)。

**例 6.** 矩阵快速幂从单位阵出发：`R = I` 是 `R = R * A^k` 循环的中性元——忘记这个
初始化是经典 bug。

## 练习

1. 下列矩阵哪些对称/三角？[[1,2],[2,3]]；[[1,2],[0,3]]；[[1,0],[0,1]]。
   *（答案：对称；上三角；两者皆是（且是单位阵）。）*
2. 两个 3×3 上三角矩阵的乘积还是上三角吗？乘两个小例子验证并猜想。*（答案：是。）*
3. 图有 10⁵ 个顶点、3×10⁵ 条边。邻接矩阵和邻接表各需多少内存（4 字节元素）？
   *（答案：约 4×10¹⁰ 字节 对 约 2×3×10⁵×8 ≈ 4.8 MB。）*
4. n×n 对称矩阵只需存多少个元素？n = 1000 时对比完整的 10⁶？
   *（答案：n(n+1)/2 = 500 500。）*
5. 两个 n×n 对角矩阵的乘积是什么？*（答案：对角阵，对角元逐点相乘——对角矩阵就是
   n 个互不干扰的标量。）*
6. 写程序：以 (r, c, v) 三元组读入稀疏矩阵，对稠密向量 x 计算 A·x，不构造完整
   矩阵。
7.（挑战）证明：既是上三角又是下三角的矩阵必为对角阵，且对角矩阵两两可交换。
