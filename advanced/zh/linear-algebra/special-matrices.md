# 特殊矩阵的概念 【6】

单位阵、三角阵、对称阵和稀疏矩阵

## 讲解

* **单位阵** I：方阵，主对角线 aᵢᵢ = 1，其余元素为 0。它是乘法的单位元：
  A·I = I·A = A，地位相当于数 1。
* **三角阵**：**上三角阵**满足 i > j 时 aᵢⱼ = 0（主对角线下方全为 0）；
  **下三角阵**上方全为 0。三角阵的乘积、逆矩阵仍是三角阵；行列式等于
  主对角线元素之积。
* **对称阵**：Aᵀ = A，即 aᵢⱼ = aⱼᵢ。只需存储 n(n+1)/2 个元素。无向图的
  邻接矩阵都是对称阵。
* **稀疏矩阵**：绝大多数元素为 0。只存非零元：三元组 (行, 列, 值)——
  **坐标表（COO）**——或邻接表。n 个顶点、m 条边的图：邻接矩阵要 O(n²)
  内存，邻接表只要 O(n + m)；稀疏图 m ≪ n² 时邻接表优势巨大。

## 例题

**例 1.** I₃ = [[1,0,0],[0,1,0],[0,0,1]]；验证 [[1,2],[3,4]]·I₂ =
[[1,2],[3,4]]。

**例 2.** 上三角阵：[[2, 5, 1], [0, 3, 4], [0, 0, 7]]——行列式
2·3·7 = 42（主对角线之积）。

**例 3.** 对称阵：[[1, 7, 3], [7, 2, 5], [3, 5, 0]]。无向图的邻接矩阵必然
对称：边 i–j 同时出现在 (i, j) 与 (j, i)。

**例 4（C++）.** 稀疏存储：三元组与邻接表：

```cpp
struct Entry { int r, c; double v; };      // COO 三元组
vector<Entry> sparse = {{0, 1, 2.5}, {3, 3, -1.0}};

vector<vector<pair<int,int>>> g(n);        // 邻接表：(邻居, 边权)
g[u].push_back({v, w});
```

**例 5.** 高斯消元最终得到的正是上三角阵——这正是消元的目的：三角方程组的
回代只需 O(n²)。

## 练习

1. 判断下列矩阵是否为对称阵/三角阵：[[1,2],[2,3]]；[[1,2],[0,3]]；
   [[1,0],[0,1]]。*（答案：对称；上三角；两者皆是（且是单位阵）。）*
2. 两个 3 阶上三角阵的乘积还是上三角阵吗？乘两个小例子验证并猜想。
   *（答案：是。）*
3. 某图有 10⁵ 个顶点、3×10⁵ 条边。邻接矩阵与邻接表各需多少内存
   （按 4 字节元素计）？*（答案：约 4×10¹⁰ 字节 vs 约 2×3×10⁵×8 ≈ 4.8 MB。）*
4. 对称 n×n 矩阵需要存储多少个元素？n = 1000 时与完整的 10⁶ 对比。
   *（答案：n(n+1)/2 = 500 500。）*
5. 编写程序：以 (r, c, v) 三元组读入稀疏矩阵，不建完整矩阵直接计算 A·x
   （x 为稠密向量）。
6. （挑战）证明：既是上三角又是下三角的矩阵必为对角阵，且对角阵之间可交换。
