# 向量与矩阵的概念 【5】

## 讲解

**向量**是有序的数元组——可以表示一个点或一段位移。写作列向量
x = (x₁, x₂, …, xₙ)ᵀ 或行向量，n 称为**维数**。

**矩阵**是按 m **行** n **列**排列的矩形数表，记作 A = (aᵢⱼ)，aᵢⱼ 是第 i 行
第 j 列的元素。m = n 的矩阵称为**方阵**。

* 行向量是 1×n 矩阵，列向量是 m×1 矩阵；
* 两个矩阵**相等**当且仅当形状相同且对应元素全相等；
* 所有元素为 0 的矩阵称为**零矩阵** O。

**几何观点**：m×n 矩阵表示从 n 维空间到 m 维空间的线性映射；A·x 就是把这个
映射作用到向量 x 上。

**在程序设计中**，矩阵是二维数组 `double a[N][M]`，向量是一维数组。它们支撑：
线性递推（矩阵快速幂）、高斯消元、图的邻接矩阵、动态规划的状态转移。

## 例题

**例 1.** A = [[1, 2, 3], [4, 5, 6]] 是 2×3 矩阵；a₂₁ = 4，a₁₃ = 3。

**例 2.** v = (3, 4)ᵀ 是 2 维列向量，模长 √(3²+4²) = 5。

**例 3.** 顶点集 {1,2,3} 上三角形图的邻接矩阵：
A = [[0,1,1],[1,0,1],[1,1,0]]——对称，对角线为 0。

**例 4.** 绕 z 轴旋转 θ 角的 3×3 矩阵：

```
[cos θ  −sin θ  0]
[sin θ   cos θ  0]
[  0       0    1]
```

**例 5（C++）.** 声明方式：

```cpp
double A[10][10];        // 10×10 矩阵
double v[10];            // 10 维向量
vector<vector<double>> B(n, vector<double>(m));   // 动态 n×m
```

## 练习

1. 设 A = [[2, −1], [0, 3], [5, 5]]，写出它的形状及元素 a₁₂、a₃₁。
   *（答案：3×2；−1；5。）*
2. [[1, 2]] 是向量还是矩阵？*（答案：都是——1×2 矩阵，即行向量。）*
3. 写出 4×4 零矩阵，以及满足 aᵢⱼ = i + j 的 2×3 矩阵。
   *（答案：[[2,3,4],[3,4,5]]。）*
4. 设 A 是图的邻接矩阵，A² 的 (i, j) 元素表示什么？
   *（答案：从 i 到 j 长度为 2 的路径条数。）*
5. 用 C++ 存储矩阵 [[1,2],[3,4]]，并通过交换下标输出它的转置。
6. （挑战）把矩阵 [[0, −1], [1, 0]] 分别作用到 (1,0)ᵀ 与 (0,1)ᵀ 上，解释
   为什么它把每个向量逆时针旋转 90°。
