# 向量与矩阵的概念 【5】

Vectors and Matrices: Concepts

## 讲解

**向量**是有序的数元组——一个点、一段位移或一个状态。写作列向量
x = (x₁, x₂, …, xₙ)ᵀ 或行向量。**维数**是 n。

**矩阵**是有 m **行** n **列**的长方形数表，记作 A = (aᵢⱼ)，其中 aᵢⱼ 是第 i 行第
j 列的元素。m = n 的 m × n 矩阵称为**方阵**。

* 行向量是 1×n 矩阵；列向量是 m×1。向量是退化的矩阵——矩阵的一切性质对向量都适用。
* 两个矩阵**相等**当且仅当形状相同且每个元素都相等。
* **零矩阵** O 的所有元素都是 0——加法单位元。

**几何视角——最该内化的理解**：m×n 矩阵是从 n 维空间到 m 维空间的*线性映射*；计算
A·x 就是把这个映射作用在向量 x 上。"线性"意味着映射保持加法和数乘：
A(u + v) = Au + Av，A(λu) = λ·Au。旋转、伸缩、投影、错切都是矩阵；反过来，每个矩阵
都是这些简单形变的组合。A 的第 j 列恰好是第 j 个基向量被映射后的落点——逐列读一个
矩阵，就能*看见*它在做什么。

**编程中**，矩阵是二维数组 `double a[N][M]`，向量是一维数组。它们驱动：线性递推
（矩阵快速幂）、高斯消元、图的邻接矩阵、动态规划的状态转移。

## 例题

**例 1.** A = [[1, 2, 3], [4, 5, 6]] 是 2×3；a₂₁ = 4，a₁₃ = 3。（下标约定：先行后
列——代码里就是 `a[i][j]`。）

**例 2.** v = (3, 4)ᵀ 是 2 维列向量；长度（模）为 √(3²+4²) = 5。

**例 3.** 顶点 {1,2,3} 上三角形图的邻接矩阵：A = [[0,1,1],[1,0,1],[1,1,0]]——
对称，对角线为 0。

**例 4.** 绕 z 轴旋转 θ 角的 3×3 矩阵：

```
[cos θ  −sin θ  0]
[sin θ   cos θ  0]
[  0       0    1]
```

逐列读：x 轴映到 (cos θ, sin θ, 0)，y 轴映到 (−sin θ, cos θ, 0)，z 轴不动——正是一
个旋转。

**例 5（C++）.** 声明：

```cpp
double A[10][10];        // 10×10 矩阵
double v[10];            // 10 维向量
vector<vector<double>> B(n, vector<double>(m));   // 动态 n×m
```

## 练习

1. 对 A = [[2, −1], [0, 3], [5, 5]]，给出它的形状以及元素 a₁₂、a₃₁。
   *（答案：3×2；−1；5。）*
2. [[1, 2]] 是向量还是矩阵？*（答案：都是——1×2 矩阵，即行向量。）*
3. 写出 4×4 零矩阵和满足 aᵢⱼ = i + j 的 2×3 矩阵。*（答案：[[2,3,4],[3,4,5]]。）*
4. 图的邻接矩阵为 A。A² 的 (i, j) 元素统计的是什么？
   *（答案：从 i 到 j 走恰好 2 步的路径数——见[矩阵的运算](matrix-operations.md)。）*
5. 矩阵 [[2, 0], [0, 3]] 在几何上对平面做了什么？
   *（答案：x 坐标拉伸 ×2，y 坐标拉伸 ×3。）*
6. 用 C++ 存储矩阵 [[1,2],[3,4]]，通过交换下标打印其转置。
7.（挑战）解释为什么 [[0, −1], [1, 0]] 把每个向量逆时针旋转 90°——把它作用在
   (1,0)ᵀ 和 (0,1)ᵀ 上，再逐列读。
