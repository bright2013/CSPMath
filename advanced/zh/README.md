# 提高级数学 (Advanced Level Mathematics)

本空间覆盖《全国青少年信息学奥林匹克系列竞赛大纲（2025 年修订版）》**提高级
（2.2，对应 CSP-S）中 2.2.5 "数学与其他"** 的全部数学要求。

## 大纲范围

| 主题 | English |
| --- | --- |
| 初等数学（高中部分） | Elementary mathematics (senior high school) |
| 初等数论 | Elementary number theory |
| 离散与组合数学 | Discrete and combinatorial mathematics |
| 线性代数 | Linear algebra |

## 难度系数

提高级数学条目的难度系数为 【5】–【7】，由 CCF NOI 科学委员会给出。本书在每个
条目旁保留相同标注。

## 先修内容

本级别直接建立在**入门级数学**之上（见入门级数学空间）：进制与四则运算、
初中代数与几何、整除与同余初步、辗转相除法、素数筛法、基本计数原理、
排列与组合。

## 来源

《全国青少年信息学奥林匹克系列竞赛大纲（2025 年修订版）》，CCF NOI 科学委员会
审定。
