# 费马小定理 【7】

## 讲解

**费马小定理**：若 p 为质数且 p ∤ a，则

> a^(p−1) ≡ 1 (mod p)

等价形式（对**任意** a 成立）：aᵖ ≡ a (mod p)。

它是欧拉定理在质数模下的特例（φ(p) = p − 1）。

**主要用途：**

* **求模逆元**（详见逆元一节）：p 为质数且 p ∤ a 时 a⁻¹ ≡ a^(p−2) (mod p)，
  用快速幂 O(log p) 求得；
* **指数化简**：p ∤ a 时 aᵏ mod p = a^(k mod (p−1)) mod p；
* **素性测试**：若对某个 a 有 a^(n−1) ≢ 1 (mod n)，则 n 必为合数（费马素性
  测试的原理；注意卡迈克尔数如 561 能骗过它）。

**快速幂**：通过反复平方在 O(log k) 内计算 aᵏ mod m，是这一切的基础工具。

## 例题

**例 1.** 2⁶ = 64 ≡ 1 (mod 7)；3⁶ = 729 = 7·104 + 1 ≡ 1 (mod 7)。✓

**例 2.** 求 2¹⁰⁰ mod 11：2¹⁰ ≡ 1 (mod 11)，故 2¹⁰⁰ = (2¹⁰)¹⁰ ≡ 1。

**例 3.** 3 模 7 的逆元：3⁵ = 243 = 7·34 + 5 ≡ 5 (mod 7)。验证：3·5 = 15 ≡ 1。✓

**例 4（C++）.** 快速幂：

```cpp
long long qpow(long long a, long long k, long long m) {
    long long r = 1 % m;
    a %= m;
    while (k > 0) {
        if (k & 1) r = r * a % m;
        a = a * a % m;
        k >>= 1;
    }
    return r;
}
// 质数 p 下的逆元：qpow(a, p - 2, p)
```

**例 5.** 561 = 3 × 11 × 17 是合数，但对每个与 561 互质的 a 都有
a⁵⁶⁰ ≡ 1 (mod 561)——卡迈克尔数，单靠费马测试无法识破。

## 练习

1. 对 a = 4，p = 5 验证费马小定理。*（4⁴ = 256 ≡ 1 mod 5。✓）*
2. 计算 5²⁰²⁵ mod 13。*（提示：5¹² ≡ 1；2025 mod 12 = 9。答案：5。）*
3. 用 a^(p−2) 求 7⁻¹ mod 11。*（答案：7⁹ mod 11 = 8；验证 7·8 = 56 ≡ 1。）*
4. 分别用 mod 10 循环节、以及 mod 5 + 费马 + 奇偶性，求 2²⁰²⁵ 的末位数字。
   *（答案：2。）*
5. 证明 341 = 11 × 31 是以 2 为底的费马伪素数（即 2³⁴⁰ ≡ 1 mod 341）但它
   是合数。
6. 实现快速幂，验证随机样例中 (a·b) mod m 的计算正确；再计算
   2^(10⁹) mod 1000000007。*（答案：140625001。）*
7. （挑战）对任意整数 a 证明 p | aᵖ − a（p 为质数）。
   *（提示：即 aᵖ ≡ a (mod p)；对 a 作数学归纳法。）*
