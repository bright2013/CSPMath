# 费马小定理 【7】

Fermat's Little Theorem

## 讲解

**费马小定理**：若 p 为质数且 p ∤ a，则

> a^(p−1) ≡ 1 (mod p)

对**所有** a 都成立的等价形式：aᵖ ≡ a (mod p)。

它是[欧拉定理](euler-theorem.md)在模数为质数时的特例，因为 φ(p) = p − 1。

**为什么指数是 p − 1。** 模质数 p 时，非零剩余 {1, 2, …, p−1} 构成乘法群：每个元素
都有逆元，乘以与 p 互素的 a 只是把它们重新排列。把整组数在排列前后各乘起来得
a^(p−1)·P ≡ P (mod p)，P 可以消去。

**主要用途：**

* **模逆元**（见[专页](modular-inverse.md)）：p 为质数且 p ∤ a 时
  a⁻¹ ≡ a^(p−2) (mod p)——用快速幂 O(log p) 计算。
* **指数降幂**：p ∤ a 时 aᵏ mod p = a^(k mod (p−1)) mod p。
* **素性测试**：若对某个 a 有 a^(n−1) ≢ 1 (mod n)，则 n 是合数（费马素性测试的
  基础；小心 Carmichael 数如 561，它能骗过这个测试）。

**快速幂**是这一切的使能工具：用平方倍增在 O(log k) 内计算 aᵏ mod m。
k = 13 = 1101₂ 意味着 a¹³ = a⁸·a⁴·a¹——逐位扫描 k 的二进制位，每步把 a 平方，
遇到 1 位就乘进答案。

## 例题

**例 1.** 2⁶ = 64 ≡ 1 (mod 7)。同理 3⁶ = 729 = 7·104 + 1 ≡ 1 (mod 7)。✓

**例 2.** 计算 2¹⁰⁰ mod 11：2¹⁰ ≡ 1 (mod 11)，所以 2¹⁰⁰ = (2¹⁰)¹⁰ ≡ 1。

**例 3.** 求 3 模 7 的逆元：3⁵ = 243 = 7·34 + 5 ≡ 5 (mod 7)。验证：3·5 = 15 ≡ 1。✓

**例 4（C++）.** 快速幂：

```cpp
long long qpow(long long a, long long k, long long m) {
    long long r = 1 % m;
    a %= m;
    while (k > 0) {
        if (k & 1) r = r * a % m;   // 取 k 的这一位
        a = a * a % m;              // a 变为 a^(2^i)
        k >>= 1;
    }
    return r;
}
// 模质数 p 的逆元：qpow(a, p - 2, p)
```

**例 5.** 561 = 3 × 11 × 17 是合数，但对每个与 561 互素的 a 都有
a⁵⁶⁰ ≡ 1 (mod 561)——Carmichael 数；单靠费马测试无法识别它。
（原因：560 是 3−1、11−1 和 17−1 的公倍数，所以同余式对每个质因子都成立，
再由 CRT 合并到模 561。）

## 练习

1. 对 a = 4, p = 5 验证费马小定理。*（4⁴ = 256 ≡ 1 mod 5。✓）*
2. 计算 5²⁰²⁵ mod 13。*（提示：5¹² ≡ 1；2025 mod 12 = 9；算 5⁹ mod 13。答案：5。）*
3. 用 a^(p−2) 求 7⁻¹ mod 11。*（答案：7⁹ mod 11 = 8；验证 7·8 = 56 ≡ 1。）*
4. 先用模 10 的循环，再用模 5 + 费马 + 奇偶性，两种方法求 2²⁰²⁵ 的个位。
   *（答案：2。）*
5. 证明 341 = 11 × 31 是以 2 为底的费马伪素数（即 2³⁴⁰ ≡ 1 mod 341），但它是合数。
6. 实现 `qpow`，用随机数据验证 (a·b) mod m 与 qpow 的结果；然后计算
   2^(10⁹) mod 1000000007。*（答案：140625001。）*
7.（挑战）对 a 作数学归纳法证明 aᵖ ≡ a (mod p)：把 (a + 1)ᵖ 用二项式定理展开，
   注意 0 < k < p 时 p | C(p, k)。
