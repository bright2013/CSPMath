# 模运算意义下的逆元 【7】

Modular Inverse

## 讲解

a 模 m 的**逆元**是满足

> a·x ≡ 1 (mod m)

的整数 x，记作 a⁻¹ (mod m)。**它存在当且仅当 gcd(a, m) = 1**，存在时在模 m 意义下
唯一。

**存在性，一句话**：a·x ≡ 1 (mod m) 表示存在 y 使 a·x + m·y = 1——一个
[裴蜀方程](bezout.md)，恰好当 gcd(a, m) = 1 时可解。

逆元让**模运算中的除法**成为可能："除以 a"变成"乘以 a⁻¹"：

> b / a (mod m) ≡ b · a⁻¹ (mod m)

这正是入门级所缺的那块拼图——那时只有 +、−、× 与同余相容。

**三种求法：**

1. **扩展欧几里得算法**——对任何满足 gcd(a, m) = 1 的模数 m 都适用：
   解 a·x + m·y = 1，则 x ≡ a⁻¹ (mod m)。O(log m)。
2. **费马小定理**——当 m = p 为质数：a⁻¹ ≡ a^(p−2) (mod p)，用快速幂。O(log p)。
3. **线性递推预处理模质数 p 的全部逆元**：
   inv[i] = (p − p/i) · inv[p % i] % p，O(n) 求出 inv[1..n]——当解题需要 1 到 n 的
   *每一个*逆元时选它。

**典型用途**：计算 C(n, m) mod p——预处理阶乘和阶乘逆元，则
C(n,m) = fact[n] · invFact[m] · invFact[n−m] mod p。

## 例题

**例 1.** 3⁻¹ mod 7 = 5，因为 3·5 = 15 ≡ 1 (mod 7)。

**例 2.** 计算 1/2 + 1/3 (mod 7)：2⁻¹ = 4，3⁻¹ = 5 → 4 + 5 = 9 ≡ 2 (mod 7)。
验证：1/2 + 1/3 = 5/6；5·6⁻¹ = 5·6 = 30 ≡ 2。✓（6 模 7 自逆。）

**例 3.** 6⁻¹ mod 9 不存在：gcd(6, 9) = 3 ≠ 1（6x ≡ 1 (mod 9) 会要求 3 | 1）。

**例 4（C++）.** 模质数时用快速幂求逆，以及 O(n) 的递推表：

```cpp
long long inv(long long a, long long p) { return qpow(a, p - 2, p); }

// 模质数 p 的所有逆元，O(n)：
inv[1] = 1;
for (int i = 2; i <= n; i++)
    inv[i] = (p - p / i) * inv[p % i] % p;
```

**例 5（C++）.** 用阶乘求 C(n, m) mod 998244353：

```cpp
fact[0] = 1;
for (int i = 1; i <= N; i++) fact[i] = fact[i-1] * i % P;
invFact[N] = qpow(fact[N], P - 2, P);
for (int i = N; i >= 1; i--) invFact[i-1] = invFact[i] * i % P;
// C(n, m) = fact[n] * invFact[m] % P * invFact[n-m] % P
```

注意这个技巧：只对 invFact[N] 做一次快速幂，再反向递推就得到*所有*阶乘逆元——
n 个逆元只花一次幂运算的代价。

## 练习

1. 手算：2⁻¹ mod 5；5⁻¹ mod 7；10⁻¹ mod 13；7⁻¹ mod 12。
   *（答案：3；3；4；7。）*
2. 哪些有逆元：4 mod 9，6 mod 15，11 mod 26？*（答案：有；没有；有。）*
3. 计算 5/3 mod 11（即 5·3⁻¹ mod 11）。*（答案：3⁻¹ = 4，所以 20 ≡ 9。）*
4. 用费马小定理计算 2⁻¹ mod 1000000007。*（答案：500000004 = (p+1)/2。）*
5. 对 p = 7, i = 1…6 验证递推式 inv[i] = (p − p/i)·inv[p%i] % p，与暴力结果对比。
6. 实现 n ≤ 10⁶ 的 C(n, m) mod 998244353，回答 q 组询问。
7.（挑战）证明递推式：写 p = q·i + r（r = p mod i），则 q·i + r ≡ 0 (mod p)，
   故 i⁻¹ ≡ −q·r⁻¹ (mod p)。
